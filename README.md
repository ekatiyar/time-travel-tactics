# Time travel tactics

Turn-based tactics with time travel shenanigans.

**[Play it →](https://ekatiyar.github.io/time-travel-tactics/)**

The front page has the tip of master plus every released version. Releases are git tags, served
at `/v/<tag>/`, so an old version stays playable forever without living in the working tree.
[`docs/hosting.md`](docs/hosting.md) covers how to cut one.
