# Time travel tactics

Turn-based tactics where your past bodies remain on the board.

**[Play it →](https://ekatiyar.github.io/time-travel-tactics/)**

## Run locally

Requires Node 22 (see `.node-version`).

```sh
npm install
npm run build && node tools/serve.mjs play
```

Then open <http://127.0.0.1:5173>.

For development, `npm run dev` rebuilds on save and serves at
<http://127.0.0.1:8000> (esbuild default port).
